# Privacy Policy for SKK Lite for Inputs

Last updated: 2026-05-09

SKK Lite for Inputs provides SKK-style Japanese input inside web page input fields.

## Data handled by the extension

The extension processes text that the user types into supported web page input fields only to provide Japanese input conversion. It also stores the following data locally in Chrome storage:

- User dictionary entries added by the user.
- Candidate selection history used to prioritize future conversion candidates.

## Data sharing

The extension does not transmit typed text, dictionary entries, candidate history, browsing history, or any other user data to the developer or to third-party servers.

## Network access

The published extension uses a bundled dictionary and performs conversion locally. Network access is used only during the developer build process to download SKK dictionary source files before packaging; this build-time process is not performed by the installed extension.

## Permissions

The extension runs a content script on web pages so it can operate inside supported input fields. It uses Chrome local storage to save user dictionary entries and candidate history.

## Contact

For privacy questions, contact the developer through the support contact listed on the Chrome Web Store item page.
